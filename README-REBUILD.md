# Lefa Motloung — Modern Personal Website

This is a rebuilt version of the supplied personal-site codebase.

## What changed
- Replaced the old vCard-style homepage with a modern responsive one-page portfolio.
- Added animated CSS developer character, floating tech badges, terminal card, orbit graphics and micro-interactions.
- Added scroll reveal animations, cursor glow, responsive mobile navigation and reduced-motion support.
- Added CV-backed sections for experience, skills, certifications and education context.
- Kept the original images, fonts, vendor libraries and other project files in place.
- Existing portfolio links were retained from the supplied codebase.

## Main files
- `index.html` — new homepage
- `css/portfolio-modern.css` — new visual/animation layer
- `js/modern-portfolio.js` — interactions and animations

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## CV source used
The website content was taken from the supplied Lefa Motloung CV. Dates and titles are presented as supplied in that CV.
